# Support

CareMesh AI is community-maintained software.

- Use [GitHub issues](https://github.com/hsussmart/caremesh-ai/issues) for bugs and feature requests.
- Use [GitHub discussions](https://github.com/hsussmart/caremesh-ai/discussions) for usage and design questions when discussions are enabled.
- Follow [SECURITY.md](SECURITY.md) for vulnerability reports.

When requesting help, include your operating system, Python and Node.js versions, deployment method, relevant sanitized logs, and the smallest reproducible example. Never include credentials or patient-identifying data.
