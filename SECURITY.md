# Security Policy

## Supported versions

Security fixes are applied to the latest revision of the `main` branch.

## Report a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting feature for this repository:

https://github.com/hsussmart/caremesh-ai/security/advisories/new

Include affected components, reproduction steps, potential impact, and any suggested mitigation. Avoid including real patient data, credentials, access tokens, or other sensitive records.

## Deployment responsibility

CareMesh AI is self-hosted. Deployers are responsible for identity configuration, network isolation, secret storage, access control, audit logging, data retention, and compliance review. Rotate any exposed credential immediately and remove it from Git history.
