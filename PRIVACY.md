# Privacy Notice

CareMesh AI is a self-hosted software project. The project maintainer does not operate a hosted service or collect data through this repository.

Deployers are responsible for configuring identity, access control, logging, retention, regional data processing, and deletion policies for their environment. Do not place protected health information, personal data, credentials, or production records in source control.

The software can connect to Azure, Microsoft Teams, FHIR services, Microsoft Fabric, model providers, and other APIs selected by the deployer. Data handling by those services is governed by the deployer's agreements and configuration.

Questions about this repository can be submitted through [GitHub issues](https://github.com/hsussmart/caremesh-ai/issues).
